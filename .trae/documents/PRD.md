# 每日晨读 - 产品需求文档

## 1. 产品概述

**产品定位**：一款极简的个人日报 PWA 应用，专为个人每日晨间阅读设计。

**核心价值**：
- 每天早上快速获取三块关键信息：天气、AI建议、AI新闻
- 作为个人的知识来源和灵感启发
- 极简设计，减少干扰，专注内容

**目标用户**：个人使用，每天早上7点前打开阅读

## 2. 核心功能

### 2.1 功能模块

| 模块 | 内容 | 数据来源 |
|------|------|----------|
| 天气卡片 | 天津当日天气：温度、天气状况、穿衣建议 | wttr.in API（免费） |
| AI建议卡片 | 每日一条赚钱或机会的小建议 | AI生成/预设库 |
| AI新闻卡片 | 当日AI界最重要的1条新闻 | 搜索引擎API |

### 2.2 页面结构

**首页（唯一页面）**：
- 顶部：日期显示 + 更新状态
- 天气卡片区块
- AI建议卡片区块
- AI新闻卡片区块
- 底部：PWA安装提示（首次访问时）

## 3. 更新机制

- **触发时机**：用户打开应用时自动获取最新数据
- **缓存策略**：
  - 若当天已获取数据且未过午夜，显示缓存数据 + 更新时间
  - 若跨天或强制刷新，获取新数据
- **数据时效**：每天早上7点前更新内容

## 4. 用户界面设计

### 4.1 设计风格：晨间简报

**视觉灵感**：清晨的第一缕阳光，温暖但不刺眼，像一杯手冲咖啡

**色彩方案**：
- 主色调：柔和的暖白色 `#FAF8F5`
- 次要色：深灰蓝 `#2C3E50`（文字）
- 强调色：琥珀橙 `#E67E22`（标题、图标）
- 渐变背景：从清晨淡蓝 `#E8F4FD` 到暖白 `#FEF9F3`

**字体选择**：
- 标题：`Noto Serif SC`（衬线体，优雅大气）
- 正文：`Noto Sans SC`（无衬线，清晰易读）

**布局风格**：
- 单页纵向滚动
- 卡片式设计，圆角柔和
- 充足的留白和间距
- 精致的阴影营造层次感

**动画效果**：
- 页面加载：卡片依次淡入上浮
- 下拉刷新：旋转加载动画
- 过渡：300ms ease-out

### 4.2 页面设计详情

| 页面 | 模块 | 设计细节 |
|------|------|----------|
| 首页 | 日期标题 | 大字居中，衬线字体，当前日期 |
| 首页 | 天气卡片 | 温度大数字 + 天气图标 + 简短描述 + 穿衣建议 |
| 首页 | AI建议卡片 | 带灯泡图标，建议文本，温暖的背景 |
| 首页 | AI新闻卡片 | 新闻标题 + 来源 + 时间 + 简要摘要 |

### 4.3 响应式设计

- **移动优先**：主要针对手机优化
- **横屏适配**：平板横屏时卡片可并排显示
- **触摸优化**：卡片间距足够，避免误触

### 4.4 PWA特性

- **可安装**：支持"添加到主屏幕"
- **离线访问**：缓存上次数据，网络不佳时仍可查看
- **启动画面**：简洁的启动画面配置

## 5. 非功能性需求

- **加载速度**：首屏 2 秒内显示
- **离线能力**：有网时更新，无网时显示缓存
- **隐私保护**：无用户追踪，数据仅本地缓存
- **无广告**：纯个人使用，无任何广告
